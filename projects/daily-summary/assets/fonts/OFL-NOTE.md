# Fonts

Theme fonts are SIL Open Font License 1.1 families, vendored as WOFF2
(latin + latin-ext subsets) under each `themes/<id>/fonts/`:

| Theme | Families |
|---|---|
| Papier | Source Serif 4, Source Sans 3 |
| Farbičky | Nunito |
| Večerná | Fraunces, Atkinson Hyperlegible |

Downloaded from Fontsource / jsDelivr CDN mirrors of the upstream OFL releases.
