# nixplay-kiosk-pages

Web pages (GitHub Pages) shown in kiosk mode on the owner's Nixplay photo frame: a home index page plus content pages, starting with daily recaps.

**Read `FRAME.md` first.** It covers the display size, the old browser engine (Chromium 81), how the frame's gestures arrive as key presses, and how "back" and "home" behave. Keep it in sync if the frame setup changes; the source of truth is the sibling project `../nixplay-kiosk`, especially `notes/kiosk-concept.md`.
